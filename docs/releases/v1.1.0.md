# 又茗花 v1.1.0 · 测试版

**中文** · [English](https://github.com/EritechX/YouMingHua/blob/v1.1.0/docs/releases/v1.1.0-en.md)

本版适配新版 ChatGPT 桌面端的界面变化，修复壁纸被遮挡、输入框底色拉长和项目预览错位，并改进 Work 对话发送后的滚动。上游引擎基线仍为 Codex Dream Skin 1.5.21。

## 修复与改进

- **模型选择器与输入框**：移除 Work 输入框中横跨模型选择器、麦克风和发送按钮背后的多余长条底色。保留原生按钮的布局和点击区域。对话底部不再叠加暗色带。
- **壁纸与项目预览**：修复工作区遮住壁纸的问题。悬停项目时，预览卡片重新贴着项目出现。
- **侧栏与对话**：侧栏选中项不再叠两层底色。追加消息保留气泡，进度和展开的工具结果各用自己的样式，报错仍可辨认。
- **发送与滚动**：在 Work 对话发出消息后，视图会跟随最新内容；手动向上翻阅时停止跟随。流式回复不再因普通正文变化反复扫描整个页面。
- **macOS**：修复窗口右侧和底部露边。窗口重开或页面切换后重新识别可换肤窗口。启动验证未通过时，日志会指出失败的检查。

## 升级与使用

退出又茗花及官方客户端后，用新安装包覆盖安装，再重新应用皮肤。现有主题和图片会保留。

macOS 要求 13 或更新版本，支持 Apple Silicon 和 Intel；安装包使用 ad-hoc 签名，未经 Apple 公证。Windows 支持 Windows 10/11 x64，安装包未签名。来源核对和首次启动步骤见[安装说明](https://github.com/EritechX/YouMingHua/blob/v1.1.0/README.md#安装)。

Work 输入框修复已在 macOS 客户端确认；Windows 桌面端的实际显示仍待试用确认，因此本版继续以预发布测试版提供。

# 又茗花 v1.0.1 · 测试版

**中文** · [English](https://github.com/EritechX/YouMingHua/blob/v1.0.1/docs/releases/v1.0.1-en.md)

本版修复 Chat 模式下模型选择器区域多余的底色，提供重新构建的 macOS 与 Windows 安装包。基于 Codex Dream Skin 1.5.21。

## 修复与改进

- 清除模型选择器、麦克风与发送按钮外层多余的胶囊底色，修复多行输入时底色横向铺满底部工具栏的问题。
- 保留原生按钮的位置、点击区域、换行布局与动画。共享样式已同步到 macOS 与 Windows。

## 升级与使用

从下方下载对应平台的新安装包，退出又茗花及官方客户端后覆盖安装，再重新应用皮肤。主题与图片会保留。

macOS 要求 13 或更新版本，支持 Apple Silicon 与 Intel；Windows 支持 Windows 10/11 x64。macOS 包使用 ad-hoc 签名，未经过 Apple 公证；Windows 包未签名。来源确认与安装步骤见[安装说明](https://github.com/EritechX/YouMingHua/blob/v1.0.1/README.md#安装)。

本次修复已在 macOS 真实 Chat 窗口确认；Windows 真实客户端视觉效果仍待试用确认，因此继续标记为预发布测试版。

# YouMingHua v1.1.0 · Test release

[中文](https://github.com/EritechX/YouMingHua/blob/v1.1.0/docs/releases/v1.1.0.md) · **English**

This release adapts the theme to the updated ChatGPT desktop interface. It restores the wallpaper, removes the stretched composer background, puts project previews back in place, and improves scrolling after you send a message in Work. The underlying engine is still based on Codex Dream Skin 1.5.21.

## Fixes and improvements

- **Model picker and composer**: Removed the extra strip behind the model picker, microphone, and send button in Work. The native layout and click targets are unchanged. The extra dark band at the bottom of the conversation is gone.
- **Wallpaper and project previews**: Fixed wallpaper hidden behind the workspace. Hovering over a project now opens its preview next to the project.
- **Sidebar and conversation**: Selected sidebar rows no longer have a double background. Follow-up messages keep their bubbles, progress updates and expanded tool results have distinct surfaces, and errors remain easy to spot.
- **Sending and scrolling**: After you send a message in Work, the view follows the latest content. Scroll up to stop following and read earlier messages. Plain text changes in a streaming reply no longer trigger repeated scans of the whole page.
- **macOS**: Fixed gaps along the right and bottom edges of the window. The theme detects eligible windows again when they reopen or switch pages. If startup validation fails, the log identifies the failed check.

## Upgrading and usage

Quit YouMingHua and the official client, install the new package over the existing copy, and reapply the skin. Existing themes and images are preserved.

macOS requires version 13 or later on Apple Silicon or Intel. The package is ad-hoc signed and not Apple-notarized. Windows supports Windows 10/11 x64; its installer is unsigned. See the [installation guide (Chinese)](https://github.com/EritechX/YouMingHua/blob/v1.1.0/README.md#安装) for source verification and first-launch steps.

The Work composer fix was confirmed in the macOS client. Visual behavior in the Windows desktop client still needs tester confirmation, so this version remains a prerelease.

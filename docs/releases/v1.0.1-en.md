# YouMingHua v1.0.1 · Test release

[中文](https://github.com/EritechX/YouMingHua/blob/v1.0.1/docs/releases/v1.0.1.md) · **English**

This release fixes the extra background around the model selector in Chat mode and provides rebuilt macOS and Windows installers. It is based on Codex Dream Skin 1.5.21.

## Fixes and improvements

- Remove the extra pill background behind the model selector, microphone and send button. It no longer stretches across the bottom toolbar when the input becomes multiline.
- Preserve native button positions, click targets, line wrapping and animations. The shared style fix is included on macOS and Windows.

## Upgrading and usage

Download the new installer for your platform, quit YouMingHua and the official client, then install over the existing copy and reapply the skin. Themes and images are retained.

Requires macOS 13 or later on Apple Silicon or Intel, or Windows 10/11 x64. The macOS package is ad-hoc signed and not Apple-notarized. The Windows package is unsigned. See the [installation guide (Chinese)](https://github.com/EritechX/YouMingHua/blob/v1.0.1/README.md#安装) for installation and source confirmation steps.

The fix has been confirmed in a real macOS Chat window. Visual behavior in the real Windows client still needs tester confirmation, so this remains a prerelease.

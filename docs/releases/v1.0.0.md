# 又茗花 v1.0.0 · 测试版

**中文** · [English](https://github.com/EritechX/YouMingHua/blob/v1.0.0/docs/releases/v1.0.0-en.md)

首个又茗花定制版，基于 Codex Dream Skin 1.5.21，提供 macOS 与 Windows 安装包。主题、背景与配套补丁已内置，无需另装开发工具或导入主题包。

## 功能与改进

- 淡粉色浅色主题与配套深色主题，跟随官方客户端的外观设置切换。
- 定制用户消息、工具调用、发送按钮及右侧面板配色；macOS 包含页面边距与外框修复。
- 首页标语：“晓看天色暮看云，行也思君，坐也思君。”
- 独立于原版 Dream Skin 的安装和状态目录，采用手动更新。

## 安装与已知限制

macOS 要求 13 或更新版本，支持 Apple Silicon 与 Intel；Windows 支持 Windows 10/11 x64。先安装并启动一次官方桌面客户端，再退出它并安装又茗花。首次启用的 Windows 独立配置可能需要重新登录。两套换肤工具不要同时运行。

[完整安装、恢复和卸载说明](https://github.com/EritechX/YouMingHua/blob/v1.0.0/README.md#安装前)。macOS 包使用 ad-hoc 签名，未经过 Apple 公证；Windows 包未签名，首次启动可能出现来源确认提示，具体处理见安装说明。

Windows 已通过 GitHub Actions 构建和自动测试，macOS 已通过本地构建及静态检查。两端新电脑首次安装、Windows 真实客户端视觉效果仍待试用确认，因此本次标记为预发布测试版。

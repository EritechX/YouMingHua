# YouMingHua v1.0.0 · Test release

[中文](https://github.com/EritechX/YouMingHua/blob/v1.0.0/docs/releases/v1.0.0.md) · **English**

The first YouMingHua distribution, based on Codex Dream Skin 1.5.21, provides macOS and Windows installers. The theme, background and compatibility patches are included; no development tools or separate theme import are needed.

## Features and improvements

- A pale pink light theme and matching dark theme, following the official client's appearance setting.
- Customized colors for user messages, tool calls, composer actions and the right panel. macOS also includes page margin and frame fixes.
- Home tagline: “晓看天色暮看云，行也思君，坐也思君。”
- Installation and state directories separate from upstream Dream Skin; updates are manual.

## Installation and known limitations

Requires macOS 13 or later on Apple Silicon or Intel, or Windows 10/11 x64. Install and launch the official desktop client once, then quit it before installing YouMingHua. The separate Windows client profile may require signing in again on first use. Do not run both skin tools at the same time.

See the [installation, restoration and removal guide (Chinese)](https://github.com/EritechX/YouMingHua/blob/v1.0.0/README.md#安装前). The macOS package is ad-hoc signed and not Apple-notarized. The Windows package is unsigned. The OS may ask you to confirm the source when opening it; see the installation guide for details.

Windows passed GitHub Actions builds and automated tests; macOS passed local builds and static checks. First installation on a fresh computer on either platform, and visual behavior in the real Windows client, still need tester confirmation. This is therefore marked as a prerelease.

Based on [Codex Dream Skin](https://github.com/Fei-Away/Codex-Dream-Skin), retaining its MIT license and copyright notices. This is not an official OpenAI product.

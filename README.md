# 又茗花

为 Codex / ChatGPT 桌面端制作的淡粉色主题，内置背景与深浅两套配色，支持跟随系统切换。

## 安装

先安装并正常启动一次官方桌面客户端，再完全退出。如正在使用其他换肤工具，请先停止皮肤并退出该工具。

### macOS

1. 打开 DMG，将「又茗花.app」拖入「应用程序」。
2. 打开「又茗花」，在屏幕顶部菜单栏找到图标，按提示完成安装。
3. 选择「应用皮肤」。若提示缺少引擎，先选择「安装 / 升级引擎…」。

安装包未经过 Apple 公证。若系统提示无法验证开发者，确认来源后可在「系统设置 → 隐私与安全性」选择「仍要打开」。

### Windows

1. 运行 EXE，按安装向导完成安装。
2. 从开始菜单打开「又茗花」。
3. 在任务栏右侧托盘中找到图标（可能收在 **∧** 内），选择「应用或重新应用」。首次启用可能需要重新登录官方客户端。

安装包未签名。若出现 SmartScreen 提示，确认来源后，可在系统提供该选项时选择「更多信息 → 仍要运行」。若被系统或单位策略直接阻止，请反馈提示，无需关闭安全功能。

## 使用与卸载

- **自动切换深浅色**：将官方客户端的外观设置为「系统 / 跟随系统」。
- **重新应用**：macOS 菜单选择「重新应用皮肤」；Windows 选择「应用或重新应用」。
- **更新**：从 [Releases](https://github.com/EritechX/YouMingHua/releases) 下载新版，退出又茗花和官方客户端后覆盖安装。
- **macOS 卸载**：先选择「恢复原状并卸载…」，再将「又茗花.app」移到废纸篓。
- **Windows 卸载**：先选择「完全恢复 Codex」，再到 Windows「设置 → 应用」卸载又茗花。

遇到问题可提交 [Issue](https://github.com/EritechX/YouMingHua/issues)，附系统与客户端版本、操作步骤及截图；Windows 请同时注明显示缩放比例。
